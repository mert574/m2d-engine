# Canvas removal

Goal: WebGL2 is the 2D floor; the Canvas 2D backend and the capability flags only it lacks go. Roadmap line: "Drop the Canvas 2D backend".

## Decisions

- Proposed by the owner on 17 Nov 2026: Canvas stays behind every renderer change and costs more than the near-zero browsers it serves.
