# m2d-kit

Ready-to-use pieces for games on [m2d](https://mert574.github.io/m2d-engine/): the stock cast, prefab templates, combat effects and helpers — compositions of the engine's capabilities, too opinionated for the engine and too reusable to live in one game.

```bash
npm install m2d-engine m2d-kit
```

Written in TypeScript; it ships compiled JavaScript with declarations, so it imports the same from either language.

Documentation: [The kit](https://mert574.github.io/m2d-engine/reference/kit).
