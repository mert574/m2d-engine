# m2d-server

The authoritative multiplayer host for [m2d-engine](https://www.npmjs.com/package/m2d-engine) games: each match in its own worker thread, signed single-use tickets, hardened WebSocket connections and state replication to clients.

```bash
npm install m2d-server m2d-engine
```

Requires Node 24 or later.
