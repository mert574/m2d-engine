# m2d-engine

A 2D game engine for the browser: Rapier physics, a batched WebGL2 renderer with a Canvas 2D fallback, a fixed and deterministic simulation tick, JSON scenes, one input API for keyboard, mouse, touch and pen, and a themable UI.

```bash
npm install m2d-engine
```

Ships as ES modules for a bundler such as Vite.

- [Documentation](https://mert574.github.io/m2d-engine/) — start with [Getting started](https://mert574.github.io/m2d-engine/guide/getting-started)
- [Live demos](https://mert574.github.io/m2d-engine/examples/) — a game per perspective, from platformer and isometric to belt scroller and auto-scroller
- [Source](https://github.com/mert574/m2d-engine)
